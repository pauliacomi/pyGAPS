Apparatus files
---------------

.. py:currentmodule:: pygaps.parsing

.. py:function:: isotherm_from_commercial(path, manufacturer, fmt, **options)

    Parse a file generated by a supported commercial adsorption apparatus and
    return a :class:`~pygaps.core.pointisotherm.PointIsotherm`.

    :param path: Path to the apparatus file.
    :param manufacturer: Manufacturer code; see the supported combinations below.
    :param fmt: File format supported for the selected manufacturer.
    :param options: Additional format-specific options passed to the commercial
        file parser.
    :returns: The parsed point isotherm.
    :rtype: :class:`~pygaps.core.pointisotherm.PointIsotherm`

    Supported manufacturer and format combinations:

    * ``bel``: ``csv``, ``xl``, or ``dat`` (BEL)
    * ``mic``: ``xl`` (Micromeritics)
    * ``3p``: ``xl`` (3P Instruments)
    * ``qnt``: ``txt-raw`` (Quantachrome)
    * ``smsdvs``: ``xlsx`` (SMS DVS)
